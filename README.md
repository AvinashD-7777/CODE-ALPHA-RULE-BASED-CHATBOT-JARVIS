# CODE-ALPHA-RULE-BASED-CHATBOT-JARVIS
Explanation of Jarvis Chatbot
Jarvis is a simple rule-based chatbot created using Python. It interacts with the user through the command prompt and responds to messages according to predefined rules.

The chatbot does not use artificial intelligence or machine learning. Instead, it checks the user’s input using if-elif-else statements and returns a suitable response.

Objective
The objective of this project is to create a basic chatbot while learning important Python concepts:

Functions.

Conditional statements.

Loops.

User input.

Program output.

String methods.

How the Chatbot Works
The chatbot follows these steps:

Jarvis displays a welcome message.

The user types a message.

The message is converted to lowercase.

Jarvis checks the message against predefined conditions.

Jarvis displays a suitable response.

The process continues until the user types bye or exit.
